# HealthVibe Mobile Client (`frontend/mobile/`)

The mobile client is built with Flutter and supports iOS, Android, and Desktop platforms. The active Flutter project is maintained in the root `mobile/` directory and referenced here.

---

## 📱 Capabilities
- Offline questionnaire completion with local database synchronization.
- Real-time push notifications for appointment reminders and doctor-approved report alerts.
- Biometric authentication (FaceID / Fingerprint) for zero-trust PHI security.
- Camera integration for medical lab report capture and OCR extraction.

---

## 🚀 Running the Mobile Client

```bash
cd mobile
flutter pub get
flutter run
```
