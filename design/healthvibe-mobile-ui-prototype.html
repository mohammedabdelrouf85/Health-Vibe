HealthVibe AI mobile-first product UI

Complete visual direction and screen set for an Arabic-first AI-assisted HealthTech workflow. The screens show patient, doctor, admin, and report surfaces with doctor-reviewed AI results.

Design principles: clinical trust, calm colors, clear status states, large patient controls, denser doctor/admin workflows, Arabic RTL support, and visible medical safety boundaries.

Primary teal#006D6F - CTAs, active states
Soft cyan#E7F7F7 - calm surfaces
Fresh green#18A058 - approved / low risk
Amber#D99A16 - pending / caution

Component and state system

Reusable UI decisions for patient, doctor, and admin flows. The same status language appears across mobile screens, dashboards, and the PDF report.

Core workflow

The product should make the review gate obvious. Patients submit data, doctors approve, and only approved results enter patient history and reports.

Patient inputSymptoms, measurements, risk factors, and consent-aware profile data.
AI assessmentRisk class, confidence, model version, and no final patient diagnosis.
Doctor reviewAssigned doctor approves, rejects, adds notes, or requests follow-up.
Patient outputApproved result, recommendations, visible disclaimer, and PDF report.
